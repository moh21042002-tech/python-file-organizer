# 📂 Python File Organizer Automation

A lightweight Python automation script designed to clean up messy folders by automatically sorting files into organized categories.

## 🚀 Built With:
- Python 3.x (`os`, `shutil`)

## 💻 How to run:
1. Clone the repository:
git clone https://github.com/moh21042002-tech/python-file-organizer.git

2. Run the script:
python organizer.py
